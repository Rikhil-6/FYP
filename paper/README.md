# Paper draft and figures

`explainable_vit_drift_routing.docx` is the current editable paper draft. It is
formatted in Times New Roman 12 point with 1.5 line spacing and uses numbered
citations in order of first appearance.

The `figures/` directory exposes the main diagrams and result panels separately
for quick review on GitHub:

- `xai_vit_architecture.png`: saliency-weighted ViT forward path and losses;
- `siamese_router_architecture.png`: historical and updated ViT comparison;
- `routing_results.png`: routed gain and the added effect of saliency losses;
- `saliency_cases.png`: helpful routes from three drift conditions.

The numerical sources for the reported plots are stored under `results/`.
